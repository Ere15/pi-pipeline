# Sprint review — проверить спринт (только чтение)

Используй скилл `/skill:sprint-review`. Правки запрещены: находки синтезируются,
фиксы диспатчатся, ревьювером не делаются.

Правила стадии:
- Выход: `REVIEW.md` — вердикт по тестам, readability-вердикт, must-fix с file:line,
  рекомендация merge / merge-after-fix / rework.
- Неподтверждённую причину помечай UNVERIFIED.
- Гейт: must-fix пуст → мерж; иначе must-fix уходит в FIX-волну.
